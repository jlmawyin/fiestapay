# Project history

FiestaPay began as a PayPal Sandbox party-payment demo. It later became Somos Panas, a multi-tenant site for groups, with a public root directory, group subdomains, accounts and Napster avatar sessions.

Earlier releases used runtime AI providers that were retired on 27 November 2026. Their code, configuration and tests are no longer part of the server; Napster is the only runtime AI. Historical evidence remains under `docs/internal/` for traceability and is not a description of the current runtime.

Current verification is recorded by CI and the latest release notes. Payments remain PayPal Sandbox only.
